# Anime Dataset Analysis

Analysis of an anime dataset using Python and Pandas.

## Project Overview

This project analyzes an anime dataset using Pandas to inspect, clean, and work with structured data.

The analysis focuses on data types, filtering, sorting, indexing, and column-based operations to answer questions about the dataset.

## Analysis Performed

* Dataset inspection
* Data type conversion
* Filtering
* Sorting
* Indexing
* Column-based analysis
* Duration analysis
* Identifying the longest-running anime

## Technologies Used

* Python
* Pandas
* Jupyter Notebook

## Key Concepts

* Pandas DataFrames
* Data type conversion
* Filtering and sorting
* Indexing
* Column operations
* `idxmax()`
* Data analysis

## Project File

`Anime-Dataset-Analysis.ipynb`

The Jupyter Notebook contains the complete analysis and implementation.

## Learning Objective

This project was created to practice Pandas operations and apply data-analysis techniques to a structured dataset.
